# Personal Portfolio

A responsive personal portfolio website developed to showcase my **academic background, technical skills, professional experience, projects, and achievements**.

## Overview

This portfolio serves as a central platform to present my journey as a **Computer Science and Engineering student**, along with my interests and experience in software and web development.

The website focuses on a clean, responsive interface with subtle animations and an intuitive navigation experience.

## Features

- Responsive and mobile-friendly design
- Structured navigation across portfolio sections
- Animated content and transitions
- Interactive typewriter effect
- Social media integration
- CV download option
- Smooth scrolling
- Responsive mobile navigation

## Technology Stack

- **HTML5** — Structure and semantic content
- **CSS3** — Styling, responsive layouts, and animations
- **JavaScript** — Interactive functionality
- **AOS** — Scroll-based animations
- **Font Awesome** — Interface and social icons
- **Google Fonts (Poppins)** — Typography

## Portfolio Sections

The website includes the following sections:

- **Home** — Introduction and professional overview
- **About** — Personal and professional background
- **Education** — Academic qualifications
- **Skills** — Technical capabilities
- **Experience** — Professional and internship experience
- **Projects** — Selected projects and work
- **Contact** — Contact and social links

## Getting Started

This is a static frontend project and does not require any backend configuration or package installation.

### Run Locally

1. Clone the repository.
2. Open the project directory.
3. Open `index.html` in a web browser.

For development, the project can also be run using **Live Server** in Visual Studio Code.

## Design & Development

The portfolio was designed with an emphasis on:

- Clean and minimal visual presentation
- Responsive layouts across screen sizes
- Accessible and intuitive navigation
- Consistent typography and styling
- Subtle animations to enhance user interaction
